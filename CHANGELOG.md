# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## 1.0.0-rc.1

First release candidate.

- `assess`: proportionate four-level triage, existing-solution search with licence checks, editable analysis axes, options and recommendation.
- `setup`: detects project conventions, installs the triage rule, proposes configuration and permission rules.
- `audit`: read-only check of decisions and setup, with an optional code comparison.
- `scripts/check-records.mjs`: optional, dependency-free check for CI.
- Behaviour scenarios, a worked example and documentation.
